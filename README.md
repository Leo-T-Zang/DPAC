# DPAC: Prediction and Design of Protein-DNA Interactions via Sequence-Based Contrastive Learning

This is unofficial repo. For official repo, please find it here [link](https://github.com/programmablebio/dpac).

## Installation

Clone this repository to get started:

```bash
git clone https://github.com/username/dpac.git
```

## Usage

### Scoring Module

To run the scoring example, execute the following command from the DPAC parent directory:

```bash
python -m dpac.example
```

### Simulated Annealing

To try the Simulated Annealing implementation, run:

```bash
python -m dpac.simulated_annealing.example
```
